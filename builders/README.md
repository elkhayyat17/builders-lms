# Builders - Civil Engineering LMS

A custom Frappe app that extends [Frappe LMS](https://github.com/frappe/lms) to create a branded, Arabic-first learning platform for civil engineering courses in the Gulf/MENA region.

## Features

- 🏗️ Civil engineering course taxonomy (5 departments)
- 🌐 Arabic-first RTL interface with English toggle
- 🎨 Professional branding (Engineering Blue + Gold/Sand palette)
- 📱 Responsive design for mobile learners
- 📹 Video lessons, PDF materials, live classes
- 📝 Quizzes and assessments
- 💬 Discussion forums per lesson

## Installation

```bash
bench get-app https://github.com/YOUR_USERNAME/builders.git
bench --site your-site install-app builders
```

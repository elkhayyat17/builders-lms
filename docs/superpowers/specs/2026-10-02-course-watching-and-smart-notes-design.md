# تصميم منظومة تجربة المشاهدة الهندسية المتقدمة والملاحظات الذكية والتفاعل
## (Next-Gen Engineering Course Watching & Timestamped Smart Notes Design Spec)

- **التاريخ:** 2026-10-02
- **المشروع:** منصة هندسة تك (Builders LMS) — كود البناء السعودي والهندسة المدنية
- **المسار المعماري:** Architectural Path
- **معايير التصميم:** UI/UX Pro Max (Cinematic Modern Dark + Coursera / Udemy Pro Workspace)

## 1. ملخص تنفيذي (Executive Summary)

تهدف هذه الوثيقة إلى تطوير وتحديث تجربة مشاهدة الدروس والفيديوهات وتدوين الملاحظات والتفاعل في منصة "هندسة تك"، بالانتقال من التخطيط الخطي التقليدي إلى **بيئة تعلم هندسية غامرة ومتكاملة (Immersive Learning Workspace)** مستوحاة من أفضل ممارسات منصات التعليم العالمية (Coursera وUdemy Pro)، مع الحفاظ التام على منظومة الحماية والبث الأمني المتطور المنجز مسبقاً (HLS AES-128, ABR Streaming, Forensic Watermark, Screen Capture Lockdown Shield).

### الأهداف الأساسية:
1. **تحديث تخطيط المشاهدة (Watch Layout):** تحويل صفحة الدرس إلى واجهة عمل متجاوبة (Split-Screen Workspace) مع زر لوضع المسرح (Theater Mode) لتكبير المخططات الهندسية.
2. **نظام الملاحظات الذكية اللحظية (Timestamped Smart Notes):** تمكين المهندس من تسجيل ملاحظات مرتبطة بدقة بالثواني بنقرة زر أو باختصار الكيبورد (`N`)، والقفز التلقائي بالفيديو لتلك اللحظة عند النقر على الملاحظة، وتصدير الملاحظات إلى PDF/مستند ملخص.
3. **شريط أدوات جانبي تفاعلي موحد (Unified Multi-Tab Sidebar):** يدمج (فهرس الدورة، الملاحظات اللحظية، الأسئلة والمناقشات الموجهة، وحقيبة المرفقات الهندسية للتحميل السريع).
4. **صفر تضارب وأداء فائق (Zero Conflict & High Performance):** الحفاظ التام على أداء الفيديو (60fps)، وعدم إحداث أي خلل في قاعدة بيانات Frappe LMS عبر استخدام الـ Custom Fields الرسمية.

## 2. الهيكل البصري وتوزيع الشاشة (Visual Architecture & Layout)

### 2.1 تخطيط أجهزة الحاسوب (Desktop Workspace - Two-Column Split):
- **الشريط العلوي (Top Nav Bar):**
  - مسار التنقل (Breadcrumbs): الدورة / الفصل / الدرس.
  - شريط التقدم اللحظي ونسبة الإنجاز الأكاديمي (`Completed 35%`).
  - أزرار التنقل السريع: الدرس السابق والتالي (`Next / Prev`).
- **العمود الرئيسي (Main Viewing Canvas ~68%–72%):**
  - **مشغل الفيديو الهندسي (Video Canvas 16:9):** إطار مريح بخلفية سينمائية هادئة (`#0B0F17`) تمنع إجهاد العينين.
  - **شريط الأدوات الفرعي أسفل المشغل:**
    - عنوان الدرس وأسماء المهندسين المحاضرين مع الشارات الأكاديمية.
    - زر تفعيل "وضع المسرح" (`Theater Mode`).
    - زر سريع لإضافة ملاحظة لحظية `[ ⏱️ أضف ملاحظة عند 02:45 ]`.
  - **قسم محتوى الدرس والنظرة العامة (`LessonOverview.vue`):**
    - عرض الشرح النظري المنسق والمعادلات الرياضية بصيغة LaTeX ($U = 1.2 D + 1.6 L$).
    - اشتراطات ومعايير كود البناء السعودي SBC 304.
- **الشريط الجانبي التفاعلي (Interactive Pro Sidebar ~28%–32%):**
  - شريط تبويبات علوي أنيق بأيقونات واضحة وحالات تركيز (Focus/Active States):
    1. 📑 **الفهرس ومسار الدورة (Outline)**
    2. 📝 **ملاحظاتي الذكية (Smart Notes)**
    3. 💬 **الأسئلة والنقاشات (Q&A)**
    4. 📎 **المرفقات الهندسية (Resources)**

### 2.2 وضع المسرح الذكي (Interactive Theater Mode):
- عند تفعيل وضع المسرح، يتوسع إطار الفيديو ليأخذ **عرض الصفحة كاملاً (100% Width)** في الأعلى لتكبير الرسومات ومخططات AutoCAD/Revit، بينما ينتقل الشريط الجانبي التفاعلي بسلاسة إلى أسفل الفيديو في شبكة مقسمة ومريحة، دون إعادة تحميل الصفحة أو انقطاع البث.

### 2.3 التجاوب مع الهواتف والأجهزة اللوحية (Responsive Mobile UX):
- يتم تثبيت المشغل في أعلى الشاشة (`sticky top-0`).
- يتحول الشريط الجانبي إلى شريط تبويبات أفقي قابل للتمرير السلس باللمس أسفل الفيديو (Overview / Outline / Notes / Q&A / Resources).

## 3. نظام الملاحظات الذكية (Timestamped Smart Notes Engine)

### 3.1 دورة حياة إنشاء الملاحظة (Creation Flow):
1. يضغط المتدرب على زر `[ + أضف ملاحظة ]` في الشريط الجانبي أو يضغط اختصار الكيبورد `N`.
2. يتم استدعاء دالة `pauseVideo()` تلقائياً في مشغل الفيديو لتجميد المشهد منعاً لتفويت أي جزء من الشرح.
3. يُقرأ التوقيت الحالي بالثواني عبر `getCurrentTime()` ويُعرض بشارة زرقاء جذابة (مثال: `[ ⏱️ 03:25 ]`).
4. يكتب المتدرب الملاحظة الهندسية في حقل الإدخال السريع.
5. عند الضغط على "حفظ":
   - تُرسل الملاحظة إلى الباك إند وتُحفظ في الدوكتايب `LMS Lesson Note`.
   - تُدرج في واجهة الملاحظات فوراً مع ترتيب زمني تصاعدي.
   - يُستأنف تشغيل الفيديو تلقائياً عبر `resumeVideo()`.

### 3.2 بطاقة الملاحظة والتفاعل الزمني:
- كل ملاحظة تُمثل ببطاقة مستقلة (Card):
  - **شارة التوقيت الزمني (Pill Badge):** زر تفاعلي يحمل التوقيت مثل `02:15`. عند النقر عليه، يقفز الفيديو مباشرة إلى الثانية 135 ويبدأ التشغيل الفوري.
  - **نص الملاحظة:** منسق ويدعم النقاط والمعادلات.
  - **قائمة التحكم:** زران هادئان لتعديل الملاحظة وحذفها.

### 3.3 تصدير الملاحظات (Export Notes to PDF/Print):
- زر أعلى التبويب يتيح للمتدرب تنزيل ملف PDF أو صفحة قابلة للطباعة منسقة تحمل شعار المنصة، اسم الدورة، اسم المتدرب ورقمه الأكاديمي، وجدولاً زمنياً مفصلاً بكافة ملاحظاته ليعتمد عليها كمرجع ميداني أو ملخص للاختبارات المهنية.

## 4. تبويبات الشريط الجانبي الإضافية (Sidebar Tabs)

### 4.1 تبويب الفهرس ومسار الدورة (Course Outline Tab):
- أكورديون منظم للفصول والدروس.
- إبراز الدرس النشط بلون أزرق هندسي وشارة "يُشاهد الآن".
- علامة خضراء `✓` للدروس المنجزة.
- مدة كل درس (مثال: `15 دقيقة`).
- الانتقال اللحظي بين الدروس بنقرة واحدة.

### 4.2 تبويب الأسئلة والنقاشات الموجهة (Lesson Q&A Tab):
- إمكانية ربط السؤال بالدقيقة الحالية في الفيديو عبر خيار: `[✓] ربط السؤال بالدقيقة [02:15]`.
- ظهور شارة التوقيت في بطاقة السؤال حتى يدرك المدرب والزملاء النقطة المحددة للشرح.
- دعم التصويت (Upvotes) والإجابات المعتمدة من المحاضر.

### 4.3 تبويب المرفقات الهندسية (Engineering Resources Tab):
- مكتبة مصاحبة لكل درس:
  - شيتات إكسل لحسابات الكود (`.xlsx`).
  - مخططات أوتوكاد وريفت (`.dwg`, `.rvt`).
  - نوتات ومذكرات حسابية (`.pdf`).
- لكل ملف: اسم الملف، وصفه، حجمه (مثال: `2.4 MB`)، وزر تنزيل مباشر `[ ⬇️ تحميل ]`.

## 5. البنية البرمجية والمكونات (Component Architecture)

```
lms/frontend/src/
  pages/
    Lesson.vue                      # الحاوية الرئيسية (Workspace Host & State Controller)
  components/
    VideoBlock.vue                  # المشغل المشفر (Exposes: getCurrentTime, seekTo, pauseVideo)
    LessonWorkspace/
      LessonPlayerSection.vue       # إطار الفيديو وشريط وضع المسرح والتحكم السريع
      LessonOverview.vue            # الشرح النظري والمعادلات ونصوص كود SBC 304
      LessonSidebar.vue             # حاوية الشريط الجانبي والتبديل بين التبويبات الأربعة
      tabs/
        TimestampedNotes.vue        # كروت الملاحظات اللحظية ومحرك القفز والتصدير
        LessonOutlineTab.vue        # شجرة الفصول ومؤشرات الإنجاز
        LessonQATab.vue             # الأسئلة المربوطة بالثواني
        LessonResourcesTab.vue      # حقيبة الملفات الهندسية والتنزيل المباشر
```

### الواجهة البرمجية لمشغل الفيديو (`VideoBlock.vue` Exposed API):
```typescript
defineExpose({
  getCurrentTime: () => currentTime.value,
  seekTo: (timeInSeconds: number) => {
    if (videoRef.value) {
      videoRef.value.currentTime = timeInSeconds
      videoRef.value.play()
    }
  },
  pauseVideo: () => {
    if (videoRef.value && !videoRef.value.paused) videoRef.value.pause()
  },
  resumeVideo: () => {
    if (videoRef.value && videoRef.value.paused) videoRef.value.play()
  }
})
```

## 7. الأمان وتوافق المنظومة (Security & Compatibility)

- **الحفاظ التام على أمان البث:** لا تمس هذه التعديلات شيفرة فك تشفير HLS AES-128، ولا العلامة المائية الجنائية الدائمة، ولا دروع رصد برامج تصوير الشاشة (Snipping Tool & PrintScreen Defense).
- **التوافق الرجعي (Backward Compatibility):** الملاحظات القديمة غير المربوطة بتوقيت تُعرض بشكل طبيعي مع وسم "ملاحظة عامة".
- **عدم التأثير على المعالج:** قراءة التوقيت والعمليات البرمجية تحدث حسب الطلب (On-Demand) دون تشغيل أي مراقبات غير متزامنة تثقل المعالج.

## 8. خطة الاختبار والتحقق (Verification & Testing)

1. **فحص سلامة البناء (Build Quality):** تشغيل `yarn build` في بيئة الدوكر والتأكد من نجاح الـ Compilation وخلو الكود من أخطاء الـ TypeCheck.
2. **فحص قاعدة البيانات والتطبيق:** تنفيذ تحديث الحقول المخصصة ومطابقتها عبر MariaDB.
3. **الاختبار الحي على متصفح Chrome الحقيقي (عبر chrome-devtools-mcp):**
   - فتح درس `SBC 304`.
   - إضافة ملاحظة عند ثانية معينة، والتحقق من التقاط التوقيت والإيقاف التلقائي للفيديو.
   - النقر على كارت الملاحظة واختبار القفز الزمني اللحظي واستئناف الشرح.
   - تجربة زر وضع المسرح واختبار التجاوب.
   - اختبار التبديل السلس بين تبويبات الشريط الجانبي (الفهرس، الملاحظات، الأسئلة، المرفقات).
   - التأكد من استمرار عمل العلامة المائية ودروع الحماية بكفاءة 100%.
